Flappy Bill - Offline Linux Restoration

Preserved from the live White House Arcade page captured September 10, 2026.
This package contains the reconstructed game and a native x86-64 Linux ELF launcher.

The launcher binds only to 127.0.0.1 (localhost), serves the embedded game from memory,
and opens it in an installed Chromium-family browser or Firefox. The game itself does
not require an Internet connection.

Controls from the preserved game:
  Click or Space: flap
  M: mute
  R: restart

Run:
  ./Flappy_Bill

This is a preservation/restoration package. No White House site navigation, analytics,
or remote page dependencies are required for gameplay.
