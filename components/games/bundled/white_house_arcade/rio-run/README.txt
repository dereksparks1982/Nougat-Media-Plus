Rio Run - Offline Archive v1

Reconstructed from the captured White House Arcade page and packaged as a native Linux x86-64 ELF localhost launcher.
Controls: arrow keys or WASD to steer, M mute, R restart. The captured mobile directional pad is preserved.

Run: ./Rio_Run
The game HTML/JavaScript/fonts are embedded in the executable and served only on 127.0.0.1.
