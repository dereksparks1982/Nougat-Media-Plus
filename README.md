# Nougat Media Suite v0.0.43

Nougat Media Suite is a native Linux media-center application from Elderred Softworks LLC. It combines local playback, media libraries, recommendations, over-the-air television, internet television, decentralized search, streaming, games, media tools, security analysis, diagnostics, and an integrated Jellyfin foundation in one desktop application.

## Home

- Continue Watching with resume progress.
- Mouse-wheel horizontal browsing over Continue Watching.
- Local and recommended media poster grids.
- Cached artwork and metadata.
- Private local viewing-history integration.

## Video Player

- Native Nougat playback for local media, Stream, P2P, Live TV, and supported internet television.
- Play, Pause, Stop, Rewind 10s, Fast Forward 10s, and Fullscreen.
- Left-click pause/resume.
- Double-click fullscreen.
- Space pause/resume.
- Left/Right seek.
- Mouse wheel and Up/Down volume control.
- Volume range up to 200%.
- Subtitle controls.
- Up Next sequential playback.
- Approved Nougat seek and volume components.
- Automatic player-information and pointer hiding.
