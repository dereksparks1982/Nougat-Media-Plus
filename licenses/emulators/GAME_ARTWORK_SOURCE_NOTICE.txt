Game artwork sources for Nougat Media Suite v0.0.44
===================================================

User-linked ROMs:
- Same-name local sidecar artwork remains first priority.
- When no sidecar exists, Nougat may request an exact-name box-art image from
  the appropriate Libretro Named_Boxarts thumbnail collection and cache it in
  the user's private Nougat cache. Nougat does not bulk-redistribute those
  thumbnail collections in this changed-files package.

Bundled legal NES Waveforms card:
- Upstream project: https://github.com/NickCulbertson/NES-Waveforms
- Project license: MIT, preserved by Nougat's existing bundled-game records.
- Nougat does NOT redistribute the README-linked NES_Thumbnail.png from the
