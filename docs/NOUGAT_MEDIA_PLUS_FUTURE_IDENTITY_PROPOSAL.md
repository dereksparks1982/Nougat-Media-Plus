# Nougat Media Plus - Future Identity Proposal

**Status:** Deferred concept only  
**Current product identity:** Nougat Media Suite  
**Current development:** v0.0.61 Drone Lab / Mission Control  
**Implementation approval:** Not granted

## Proposed future name

**Nougat Media Plus**

The name is being retained as a possible future replacement for **Nougat Media Suite** because it presents Nougat as one unified media platform with expanded capabilities rather than only a collection of tools.

## Branding impact if approved later

A future conversion must be handled as a separate product-wide identity revision. It would require explicit review of the application name, header branding, launcher identity, executable naming, window identity, packaging, GitHub/documentation text, and all user-visible product-name references.

## Icon direction

The current approved Nougat **N** remains authoritative for **Nougat Media Suite**. If **Nougat Media Plus** is adopted, a new or deliberately revised icon must be designed and approved before implementation. The existing icon must not be casually changed during unrelated feature work.

## Current decision

- Do not rename the application during v0.0.61.
- Do not change the current Nougat N icon during v0.0.61.
- Continue the v0.0.61 Drone integration under **Nougat Media Suite**.
- Revisit **Nougat Media Plus** later as a separate branding decision.
