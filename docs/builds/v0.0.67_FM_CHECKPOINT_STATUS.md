# Nougat Play Portal v0.0.67 FM Checkpoint

This is an intentionally partial changed-files checkpoint from the approved v0.0.67 FM build.
It is not the final v0.0.67 application release and does not claim physical HVR-955Q FM validation.

Included work:
- Native V4L2 radio provider source/header.
- V4L2 radio probe, tuning, signal percentage and stereo detection support.
- Frequency conversion support for V4L2 62.5 Hz LOW units and legacy 62.5 kHz units.
- Standalone unit test source.
- Prebuilt unit-test binary from the build workspace.

Validated in the build workspace:
- Provider/test compile with -Wall -Wextra -Werror.
- Frequency conversion unit test passes.

Not yet included/completed in this checkpoint:
- Integration into RadioBackend.
- CMake application integration.
- Shared DVB/FM tuner ownership implementation.
- cx231xx/Si2157/cx25840 kernel patch bundle.
- HVR audio capture/routing.
- HVR hardware scan validation.
- Physical FM audio validation.
- TV -> FM -> TV hardware regression validation.
- Final v0.0.67 executable.

GitHub policy for this checkpoint:
- No commit, tag or push is performed by the apply script.
- GitHub remains untouched.
