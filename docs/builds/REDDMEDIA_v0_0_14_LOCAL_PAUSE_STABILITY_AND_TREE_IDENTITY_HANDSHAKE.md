## Risks and controls

- libVLC calls can block the single X11 event thread. Paused periodic rendering therefore uses cached timing and cached chapter state.
- libVLC stop/release may still block inside third-party code. Final application shutdown uses a three-second bounded teardown; if that bound is exceeded, ReddMedia closes the X display and terminates the process so the user is not left with an uncloseable window.
- Icon caches can retain stale artwork. The installer replaces user-level app and MIME icon copies at all project sizes, refreshes the GTK icon cache and desktop database, assigns the raw-executable custom icon after the final binary write, and refreshes Nautilus when present.
- Owner-side visual confirmation is still required because metadata readback cannot prove what GNOME displays.

## Continuation point after install

Owner validation is required before acceptance: local episode playback, one-minute pause/resume, five-minute pause/resume, close while paused, reopen/resume position, repeated pause/resume cycles, and visual tree confirmation on dock/app switcher/launcher/raw executable/top-right version badge.
