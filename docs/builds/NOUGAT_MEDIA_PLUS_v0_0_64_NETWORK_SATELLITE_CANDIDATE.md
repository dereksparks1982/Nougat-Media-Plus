# Nougat Media Plus v0.0.64 Network Center and Satellite Systems Foundation

Candidate built from the owner-accepted v0.0.63 baseline.

## Scope
- Adds top-level Network immediately before System.
- Search main tabs become Search / Crawler / P2P / Archive.
- Existing peer-node controls are retained under P2P as Downloads / Peer Network.
- Virus Scan moves to System.
- Adds Network Overview, Connections, Devices, Security, Satellite, Diagnostics and Logs.
- Network Security is defensive observation and exposure reporting, not exploitation tooling.
- Adds Satellite Track, Passes, Receive, Decode, Transmit, Imagery, Antenna, Hardware and Logs foundation.
- Integrates the MIT-licensed Andrew C. Young C99 SGP4/SDP4 component supplied by the owner.
- Detects GDAL, RTL-SDR, SoapySDR and Hamlib command tooling honestly when present.
- Satellite TX remains DISABLED unless a real future transmitter backend is implemented and connected.
- No Games or Xbox source/runtime files are modified by this candidate.

## UI geometry
New Search/P2P/Network/Satellite tab strips use connected tactical segments with diagonal slash seams. Only the far-left and far-right segments have finished outside ends; intermediate segments connect directly.
