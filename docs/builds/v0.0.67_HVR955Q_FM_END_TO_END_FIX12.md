## FIX12 correction

FIX12 changes the `cx231xx_set_audio_input()` patch anchor so it no longer
assumes `case AUDIO_INPUT_TUNER_TV:` is immediately followed by `default:`.
It removes the one abandoned upstream FM stub and attaches FM to the existing
tuner SIF path by matching the TV case label itself. This is specifically
designed to tolerate the exact Ubuntu 7.0.0-31.31 source layout that stopped
FIX9 before any module build or install occurred.


## FIX12 correction

FIX12 corrects two related cx231xx FM-audio integration errors:

1. The unfinished `AUDIO_INPUT_TUNER_FM` case is in
   `cx231xx_set_audio_decoder_input()`, not `cx231xx_set_audio_input()`.
   The kernel patch now modifies the decoder function directly.

2. The radio-open path now calls
   `cx231xx_set_audio_decoder_input(dev, AUDIO_INPUT_TUNER_FM)`.
   It no longer passes the `AUDIO_INPUT_TUNER_FM` enum to
   `cx231xx_set_audio_input()`, whose second argument is a board input index.

The FM case body is matched independently of its historical TODO/comment text,
removed if present, and reattached immediately before the established tuner-TV
SIF decoder path. This keeps FM on the same proven SIF transport without
depending on a brittle source comment.


## FIX12 app-runtime correction

FIX11 proved the kernel patch, all four matched media modules, and the Nougat
v67 application build. The only failure was the pre-install `--version` smoke
test while the executable still lived in `build/app-v67`.

Nougat's executable RPATH is relative to `$ORIGIN` and points to:

- `$ORIGIN/components/ai/runtime/lib`
- `$ORIGIN/components/ai/runtime/lib64`

That is correct after the executable is copied to the Nougat project root.
Inside `build/app-v67`, however, `$ORIGIN` is the build directory, so
`libllama.so.0` cannot be found there.

FIX12 preserves the project-root RPATH and supplies the real bundled AI runtime
through `LD_LIBRARY_PATH` only for the build-directory smoke test. The final
installed root executable is still tested normally, with no loader override,
so the real project-root RPATH remains verified.

FIX12 also normalizes timestamps on changed app sources before CMake to prevent
the ZIP timestamp from causing a false clock-skew warning.
