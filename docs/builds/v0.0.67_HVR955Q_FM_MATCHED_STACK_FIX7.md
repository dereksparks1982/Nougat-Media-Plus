# Nougat Media Plus v0.0.67 HVR-955Q FM Matched Stack Fix 7

Fix 7 targets the radio driver itself. It does not rebuild Nougat with CMake.

The cx231xx family is built as one matched set:
- cx231xx
- cx231xx-dvb
- cx231xx-alsa
- si2157

The public cx231xx header ABI is unchanged. cx231xx-dvb now passes explicit
V4L2_TUNER_RADIO mode to Si2157 when the cx231xx radio path is active. The
HVR-955Q board gets a V4L2 radio node, the HVR FM IF is 6.6 MHz, and Si2157's
unfinished FM path is enabled with the existing 1.7 MHz analog machinery.

The installer does not unload the live media/audio/USB stack. It installs the
four-module set under updates/nougat-v67-fm, runs depmod, and updates initramfs
for the next normal boot.

Git and GitHub are untouched.


## FIX8 correction

FIX7 stopped before compilation because its `cx231xx-dvb.c` patch anchor
mistakenly searched for the literal characters `\t` instead of matching the
actual whitespace in the kernel source. FIX8 replaces that brittle anchor with
a whitespace-tolerant regular expression and is idempotent with the partial
FIX7 source edits already present.

No live driver unload/reload is added. No CMake configure/build is added.
