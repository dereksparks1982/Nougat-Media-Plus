# Nougat Media Plus v0.0.67 HVR-955Q FM FIX13

FIX12 successfully completed the HVR-955Q kernel patch, compiled the matched
`cx231xx`, `cx231xx-dvb`, `cx231xx-alsa`, and `si2157` modules, integrated the
native V4L2 FM application backend, built the v67 application, and installed the
root application and Nougat N desktop icon.

The final FIX12 verification failed because the previous driver override had
been renamed to a sibling directory under:

`/lib/modules/<kernel>/updates/nougat-v67-fm.fix12-old-*`

`depmod` indexes modules anywhere below `/lib/modules/<kernel>`. Therefore the
backup copy was still a live module candidate and `modinfo` resolved `cx231xx`
to the backup directory rather than the intended active directory:

`/lib/modules/<kernel>/updates/nougat-v67-fm`

FIX13 is a continuation, not another driver or application rebuild. It:

1. verifies the already-installed four matched FIX12 modules,
2. moves sibling Nougat FM backup directories completely outside `/lib/modules`,
3. rebuilds the module dependency index,
4. verifies all four module names resolve to the intended active directory,
5. regenerates the initramfs,
6. verifies the installed v0.0.67 executable, native HVR FM marker, and approved
   Nougat N icon.

No live media/audio modules are unloaded or reloaded. A normal reboot is
required only after FIX13 reaches its final PASS.
