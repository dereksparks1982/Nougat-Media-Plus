# Nougat Play Portal - Future Identity Proposal

**Status:** Deferred concept only
**Current product identity:** Nougat Play Portal
**Current development:** v0.0.61 Drone Lab / Mission Control
**Implementation approval:** Not granted

## Proposed future name

**Nougat Play Portal**

The name is being retained as a possible future replacement for **Nougat Play Portal** because it presents Nougat as one unified media platform with expanded capabilities rather than only a collection of tools.

## Branding impact if approved later

A future conversion must be handled as a separate product-wide identity revision. It would require explicit review of the application name, header branding, launcher identity, executable naming, window identity, packaging, GitHub/documentation text, and all user-visible product-name references.

## Icon direction

The current approved Nougat **N** remains authoritative for **Nougat Play Portal**. If **Nougat Play Portal** is adopted, a new or deliberately revised icon must be designed and approved before implementation. The existing icon must not be casually changed during unrelated feature work.

## Current decision

- Do not rename the application during v0.0.61.
- Do not change the current Nougat N icon during v0.0.61.
- Continue the v0.0.61 Drone integration under **Nougat Play Portal**.
- Revisit **Nougat Play Portal** later as a separate branding decision.
