For v0.0.42 and future builds, the active Nougat application icon must come from the rounded-square chocolate/caramel **N** emblem at the top center of the owner-approved Nougat UI component sheet.

Authoritative sheet in this repair package:
- `docs/design/NOUGAT_UI_COMPONENT_SHEET_APPROVED.png`
- dimensions: 1536 x 1024
- SHA-256: `a37fb2dd309af0404c615c6f2519da748952d194e44d7b796bf7d46353e92e62`
- this file is the exact owner-uploaded `NougatSpriteSheet(7).png` bytes used for the rejected-v0.0.42 icon repair.

Approved extracted N master:
- `assets/icons/nougat-media-suite-concept-sheet-v24.png`
- SHA-256: `681ece987dd00d9958cf953939403bd71a5ad9d70d8ad284e133272a0204d804`

The approved master is the top-center N emblem from the sheet. It is the only artwork permitted for active Nougat launcher, Files/Nautilus executable metadata, X11 window/dock/app-switcher, and in-app identity surfaces. Generic executable icons, gear icons, text placeholders, alternate N artwork, and regenerated substitutes are release failures.
