# ReddMedia Changelog

## v0.0.1 - VLC-Style Base Video Player

### Added

- Added top-level executable named `ReddMedia`.
- Added standalone Linux desktop player window.
- Added VLC/libVLC runtime playback integration.
- Added Open media behavior.
- Added play/pause, stop, seek, time display, fullscreen, and volume controls.
- Added double-click video fullscreen toggle.
- Added Escape-to-exit-fullscreen behavior.
- Added 3-second mouse pointer auto-hide over the video area.
- Added mouse pointer restore on movement.
- Added clean close path for playback shutdown and process exit.
- Added local resume session file.
- Added startup Resume / Load Different File choice.
- Added README, roadmap, license, third-party notices, build handshake, and validation record.

### Excluded

- P2P.
- YT-DLP.
- Media library.
- Music library.
- Photos.
- Playlists.
- Module loader.
- LAN/server mode.
- Web browser app.
- GitHub setup.
